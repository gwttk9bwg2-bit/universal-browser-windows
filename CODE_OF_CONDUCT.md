# Code of Conduct

We want this project to be useful, welcoming, and safe for contributors of every background and experience level.

Be respectful, discuss technical decisions rather than people, accept constructive feedback, and avoid harassment, threats, discrimination, doxxing, or publishing another person's private data. Maintainers may edit or remove harmful content and restrict participation when necessary.

Report conduct concerns privately to the project owner through their GitHub profile. Include links or screenshots and do not escalate private disputes in public issues.
