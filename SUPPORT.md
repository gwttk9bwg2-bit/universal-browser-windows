# Support

Use [GitHub Discussions](https://github.com/gwttk9bwg2-bit/universal-browser-windows/discussions) for questions and usage ideas. Use [GitHub Issues](https://github.com/gwttk9bwg2-bit/universal-browser-windows/issues) for reproducible bugs and feature proposals.

Before opening a bug, run the diagnostics script and remove cookies, tokens, credentials, personal URLs, and private page content from logs or screenshots.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) and do not open a public issue.
